Drag 是 · the 是…的 pattern

Read the grammar first, then decide for 25 sentences whether 是 belongs there or not.

What 是…的 actually does

Use this pattern when both people already know the action happened. You are not reporting the news. You are pointing at one detail of it — when, where, how, or with whom.

Compare: 他来了。 tells me he came. 他是坐飞机来的。 assumes I know he came, and answers how.

Subject + 是 + the detail you stress + Verb + 的 是 sits immediately before the stressed part

Two situations, two habits

Keep 是 — you're stressing a detail
我是昨天来的。
I came yesterday.
  • Time — 昨天, 去年, 八点
  • Place — 在书店, 在北京
  • How — 坐飞机, 坐地铁
  • With whom — 跟朋友一起
Drop 是 — you're giving the purpose
我来看你的。
I came to see you.
  • Shape is 来 / 去 + verb + 的
  • The whole phrase is one lump — there is no single word to stress
  • 是 here is not an error, but speakers usually leave it out
The one-second test. Ask what the underlined part answers.
When / Where / How / With whom → put 是 in.  ·  Why did you come → leave it blank.

Three things that trip students up

1. 的 always stays. You can drop 是, never 的. 我来买水果的。 ✔   我来买水果。 ✘ (different meaning — a plain future plan)

2. In a negative sentence 是 can never go. 我不是来旅游的。 ✔   我不来旅游的。 ✘

3. Questions keep 是. 你是在哪儿买的？ — you're asking about the place, so 是 stays.

Honest note for advanced students: in the "drop 是" sentences, adding 是 is not grammatically wrong. This drill trains the version a native speaker would say. In the exercise those count as incorrect so the habit sticks.
